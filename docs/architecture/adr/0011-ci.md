# ADR-0011: CI — GitHub Actions Linux cho lõi, Xcode Cloud cho app

- Trạng thái: Đề xuất (decisions-open D5)

## Quyết định (đề xuất)
- **GitHub Actions, Linux** (rẻ, nhanh) cho mọi PR: `swift test` trong `Packages/LifeOSCore`, `check-core-imports.sh`, `generate.py --check`, `reference/run_all.py --check`, `plan_graph.py --check`. File: `.github/workflows/core.yml`.
- **Xcode Cloud** (25 giờ/tháng có sẵn trong gói Apple Developer) cho build app, test UI, test hiệu năng, TestFlight. Bật từ LOS-060.
- Job cross-compile Android cho lõi: thêm khi bắt đầu GĐ Android (không chặn MVP).

## Lựa chọn
| | Xcode Cloud | GH Actions macOS | GH Actions Linux |
|---|---|---|---|
| Build/test app, TestFlight | Có, 25 giờ miễn phí | Đắt (phút macOS ×10) | Không |
| Test lõi thuần | Phí giờ | Đắt | **Có, rẻ** |
